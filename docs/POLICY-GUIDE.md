# 規則怎麼被執行

## 為什麼不是「寫進文件就好」

一條規則只寫在文件裡，會遇到兩種失效：**AI 沒載入那份文件**，或者**載入了但還是沒照做**。反過來，把所有規則都塞進 prompt 又很浪費——而且把**本來就可以機械判定**的事交給語言模型判斷，是把確定的東西換成機率的。

所以規則依**可判定性**分四級，各級由不同機制承接。

## 四級

| 級別 | 誰執行 | 判定方式 | 例子 |
|---|---|---|---|
| **硬性不變式** | 工具呼叫前擋下 | 完全機械、零語意 | 不准把改動直接併進主幹；不准代按「送審」；不准放寬 linter 設定讓紅燈消失 |
| **流程不變式** | 流程狀態閘 | 機械讀狀態、掃樹 | 沒過驗證不准開 PR；文件沒同步就紅燈 |
| **語意要求** | 評測 | 需要語意判斷 | 沒實測就不准寫數字；動手前先找有沒有可重用的 |
| **建議** | skill 正文 | 靠模型遵循 | 階段之間不要一直問人「要不要繼續」 |

**最重要的分界在前兩級與後兩級之間**：前兩級**擋得住**，後兩級**只是說明**。所以一條規則被歸在哪一級，等於在宣告它有多強的保證——這件事不能含糊。

## 三條你可以驗證的保證

**1. 擋人的東西一定查得到來源**

任何一支「擋得住」的 hook，都必須有一條正式登記的規則指向它。反過來也查：規則指名的執行者必須真的存在。**一條擋人的規則沒有正式來源，就查不到是誰定的、也沒有測試在守它**——這個雙向檢查是機械的，少一邊就紅燈。

**2. 多條規則同時適用時，最嚴的贏**

不會投票、也不會取最寬鬆的那條。而且**所有擋你的理由會一次列全**，不是修一項再撞下一項。

**3. 讀不到狀態時，該擋的照擋**

有些規則標了「狀態讀不到就擋」。這類規則在判定所需的資訊缺失或壞掉時**擋下而不是放行**——因為「沒讀到」不等於「沒違反」。沒標的規則維持放行，那是逐條考慮過的取捨，不是疏漏。

## 例外怎麼走

**環境變數不會變成無記錄、無範圍的永久逃生口。**

真的需要例外時，走的是一張有以下欄位的授權：**哪條規則、適用到哪個目標、什麼時候到期、為什麼、誰核准的**。缺任何一欄都不算數；過期了也不算數。而且**只有被標成「可核准繞過」的規則才吃這一套**——不可繞過的規則，就算拿著完全相符的有效授權也照樣擋。

每一次動用都會寫進一份只增不改的帳本，之後查得到「這個逃生口被用過幾次、誰核的、為什麼」。

## 想新增或修改一條規則

說一句「以後都要…」或「把這條規則加進去」就會進入規則變更流程。它**不會直接動手改文件**，而是先分析：

| 分析結果 | 它會做什麼 |
|---|---|
| 跟某條完全一樣 | 改既有那條，不再開一條 |
| 跟某條相容 | 擴充既有那條 |
| 跟某條互斥、但排得出優先序 | 在兩條上各寫明適用條件 |
| 跟某條真的矛盾 | **停下來只問你一題**：哪一條贏。**沒拿到答案前不開票、不寫規則** |
| 判斷不出來 | **停**——補清楚再說，不會猜 |

接著把規則歸到五層架構的某一層（歸不出層通常代表它其實是兩條規則），決定由哪一級執行，寫成一張九區塊的提案票，再走完整的開發流程。

## 為什麼 PR 不能只改文件

一次完整的規則變更，依它的級別**至少要動到這幾面**——少一面就紅燈，並指名少了什麼：

| 級別 | 必動 |
|---|---|
| 硬性不變式 | 規則登記 ＋ 人讀的文件 ＋ **執行它的 hook** ＋ 測試 |
| 流程不變式 | 規則登記 ＋ 人讀的文件 ＋ **執行它的檢查腳本** ＋ 測試 |
| 語意要求 | 規則登記 ＋ 人讀的文件 ＋ 評測案例 |
| 建議 | 規則登記 ＋ 人讀的文件 ＋ skill／agent 正文 |

這條擋的是最常見的形狀：**規則有寫、沒有任何東西在執行它**。

順帶一提，「只改了 hook 的測試」不算「改了 hook」——否則加個測試就能過閘。

## 自動最佳化碰不到什麼

skill 最佳化工具可以改 skill 正文（那正是它該做的事），但**永遠不准動**：規則登記本身、擋人的 hook、例外授權的判定實作、評測的評分基準與金標。

理由很簡單：**讓自動最佳化去改規則與評分基準，等於讓被考的人改考卷。**

而且它**只產候選**，不直接覆寫正式的 skill；候選要被接受，前提是品質不低於基準線——**品質沒量到也不接受**（沒量不等於沒退步）。過了品質這關，才輪到比 token。

## 怎麼驗證

- 隨便挑一支會擋你的 hook，確認它在規則登記裡找得到對應的一條。
- 故意寫一個只改文件的規則變更，確認它被擋下並且**告訴你少了哪幾面**。
- 拿一條「不可繞過」的規則，給它一張完全相符的有效授權，確認**仍然被擋**。
