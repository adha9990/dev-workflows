# 安裝與來源：`/setup` 怎麼用

## 什麼時候用

- 第一次在一個專案裡用 loops-workflow。
- 想換掉、停用或更新某個外部來源。
- 懷疑某個來源壞了，想做健康檢查。

```
/loops-workflow:setup
```

## 它會做什麼

`/setup` 不是安裝腳本，是**對帳**：

1. **問**你要哪些來源（必裝的不問）。
2. **算差**：你想要的狀態 vs 目前實際的狀態。
3. **只對真的有差的那幾個動手**。

所以**重跑一次是安全的**——選擇沒變就什麼都不動。這是刻意的：一個不敢重跑的安裝指令，等於沒有安裝指令。

## 會問你什麼

| 類別 | 怎麼問 | 目前有什麼 |
|---|---|---|
| 必裝 | **不問**，一律裝 | `code-graph`（跨檔案的符號與依賴查詢）、`prompt-eval`（跑語意級規則的評測） |
| token 最佳化 | **互斥、擇一或停用** | `token-optimizer-primary`（推薦） |
| 建議 | 預設勾選、可取消 | `skill-optimizer`（依實測結果改寫 skill 正文） |
| 選用 | 預設不勾 | `symbol-aware-editor`（以符號為單位的編輯與重構） |

**互斥是什麼意思**：同一個能力的兩個實作**不會同時啟用**。它們會搶同一段處理、效果與責任邊界會變得無法判斷。選了新的，舊的會在同一次操作裡被關掉。

**為什麼有些東西你在選單看不到**：一個來源要出現在選單，得先通過資格審查（平台實測、hook 掛載順序、輸出忠實度、失敗隔離、rollback、真實 benchmark）。**任一項沒過、或根本沒量過，就不會出現**——而且不提供任何「我自己承擔風險」的旗標。想知道被擋掉了什麼、還缺什麼，`/setup` 的輸出會列出來。

## 每一步怎麼安裝

固定三段：

```
staged install  →  健康檢查 / canary  →  原子切換
```

任一段失敗就**回上一個可用版本**，那一步標成已回滾。**一步失敗不影響其餘步驟**（各來源獨立），但失敗的那一步**絕不留半套**。

版本永遠取**當下的最新穩定版**，不會釘死在某個版本——但 receipt 會記下**實際解析到的版本**，之後查得到當時裝的是什麼。

## 自動更新

每個來源有自己的更新間隔（有些設成永不自動更新）。到期時會重新確認最新穩定版；**沒到期就不查、不動**。

**來源更新只做相容性與 canary 檢查，不會自動改你的 repo 內容**——升級一個工具不該順手改你的專案。

## 你會拿到什麼（receipt）

每次跑完會給一張表：

| 來源 | 動作 | 解析到的版本 | 健康檢查 | 回滾 | 說明 |
|---|---|---|---|---|---|

這是之後回答「當時到底裝了什麼、有沒有壞過」的唯一依據。

## 怎麼驗證有生效

1. **重跑一次 `/setup`，選一樣的東西** → 應該全部是 `no-op`，什麼都沒動。如果它又重裝了一遍，那是 bug。
2. **切換互斥組** → receipt 上應該看到舊的 `switch-off` 與新的 `install`，在**同一次**操作裡。
3. **停用某個選用來源** → 下次重跑時它應該維持關閉、不會自己回來。
4. **健康檢查**：對 code graph 來源，正常狀態是「已索引、狀態 ready、節點與邊的數量非零」。

## 出事了怎麼辦

| 症狀 | 怎麼做 |
|---|---|
| 某個來源裝到一半失敗 | 看 receipt 的「回滾」欄——正常情況它已經回到上一個可用版本。如果那一欄是「否」，代表連回滾都失敗了，需要手動處理該來源。 |
| 裝完之後行為變怪 | 重跑 `/setup`，把那個來源停用，確認問題是不是它造成的。 |
| 選單裡沒有你想要的來源 | 看 `/setup` 輸出的「未進選單」——它會列出還缺哪幾項資格審查。 |
| 不確定現在裝了什麼 | 重跑 `/setup`：算完差之後的 plan 就是目前狀態的對照。 |

## token 最佳化：它不會偷偷刪掉證據

啟用 token 最佳化之後，每一次壓縮都要通過同一道驗收：**規則擋下了什麼、哪個測試紅了、exit code、`檔:行`、security finding** 這些**受保護的證據不得被壓掉**。

判準是「條數不得減少」——壓縮本來就會改排版，但證據的條數不該變少。**任何一項少了，那次壓縮就會被丟掉、改用原始輸出**。optimizer 壞掉（丟例外、回空的、回非文字）也一樣。

換句話說：**壞掉的 optimizer 只會讓你少省一點 token，不會讓你拿到殘缺的證據。**
