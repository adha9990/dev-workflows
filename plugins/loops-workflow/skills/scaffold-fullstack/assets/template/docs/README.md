# docs/ — 教學文檔

這個資料夾存放專案的**教學文檔**:每個環境、功能或概念「怎麼用、有什麼限制與坑、擴充時怎麼判斷」。
它不是 API 參考,也不是決策敘事的紀錄;它是讓新人與 AI agent 快速接手、避免踩坑的地方。

## 工作慣例(請遵守)

> **每當你建立或改變一個環境、功能、或概念,就在這裡留下一份對應的教學文檔。**

- 檔名用主題:`docs/<topic>.md`(例:`testing.md`、`import.md`、`auth.md`)。
- 內容重點是「怎麼用 + 約束不變式 + 擴充時的判斷準則」;「為什麼這樣設計」最多一句;逐行細節留給
  程式碼註解;「評估過哪些方案」的敘事放 PR / 設計文件。
- 寫完在下面的索引加一行。

詳見根目錄 `AGENTS.md` 的「邊建邊留教學文檔」。

## 新人閱讀順序

1. 本檔(你在這)
2. [`architecture.md`](./architecture.md) —— 系統全景、分層、依賴規則、前後端牆
3. [`testing.md`](./testing.md) —— 測試怎麼分、加新測試怎麼選
4. 你要動的領域對應的 `docs/<topic>.md`
5. 程式碼(從 `Note` 垂直切片開始看最快)
